# Soundfonts

## `Nylon_Guitar.sf2`

Contém apenas o violão de náilon (preset General MIDI 24, "Concert Nylon
Guitar"), extraído pelo autor deste projeto do soundfont
**Live HQ Natural SoundFont GM V3.0**, de **UnderxPipe1985**:
<https://musical-artifacts.com/artifacts/1176>.

O soundfont original é licenciado sob **Creative Commons BY** (atribuição), e
este arquivo é distribuído sob a mesma licença. Modificação feita: remoção de
todos os outros presets.

## Outros soundfonts

O `cfguitar` aceita qualquer soundfont General MIDI com `--soundfont`. O
`Live_HQ.sf2` completo (~900 MB) pode ser baixado no link acima; ele não fica
no repositório porque passa do limite de 100 MB por arquivo do GitHub.
